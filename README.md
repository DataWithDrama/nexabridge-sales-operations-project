# NexaBridge Sales Operations and CRM Project

> An independent portfolio project showing how a reseller inquiry can be managed from the first request to quotation, follow-up, deal closure, and a simple order handover.

## Why I created this project

I created this project after finding a working-student sales position that interested me. I did not have professional sales experience, so I wanted to understand the actual process instead of only reading about it.

I first completed the HubSpot Inbound Sales Certification. Then I built this fictional project to practise CRM setup, opportunity tracking, quotations, follow-ups, reporting, and process documentation.

## Business scenario

NexaBridge Technology Distribution GmbH is a fictional ICT distributor. It sells hardware, software, cloud subscriptions, cybersecurity products, and supporting services through resellers.

Everything in this repository is synthetic. The companies, contacts, end customers, opportunities, prices, and documents do not represent real business data.

## Process covered

The project follows this sales-support process:

New Inquiry
→ Qualified
→ Requirements Clarified
→ Pricing Requested
→ Offer Prepared
→ Offer Sent
→ Negotiation
→ Closed Won or Closed Lost
→ Simple Order Handover for a won deal


The process stops at the handover to Order Management. Delivery, invoicing, and payment are outside the project scope.

## Dashboard KPIs

The Excel dashboard includes:

- Open opportunity count
- Open pipeline value
- Weighted pipeline value
- Won deal value
- Closed-deal count
- Win rate
- Overdue follow-ups
- Expiring quotations
- Pipeline value by stage
- Opportunities by product category
- Deal-outcome overview

Example calculation:

```text
Weighted value = Deal value × stage probability
€61,400 × 60% = €36,840
```

Weighted pipeline is a planning estimate. It is not guaranteed revenue.

## What I did myself

I completed the HubSpot Inbound Sales Certification and configured the HubSpot CRM environment. I created the pipeline and custom properties, imported and checked the records, corrected mapping problems, associated contacts and deals with companies, exported and attached the quotation PDFs, added the CRM note, and created the Visio process map.

## How AI supported the project

AI supported the generation and structure of the fictional dataset, Excel import files, quotation templates, dashboard formulas, and early drafts of the written content.

I reviewed the outputs, corrected problems, asked questions when I did not understand something, and simplified parts that looked too advanced for my current level. I do not present this project as previous professional sales employment or claim that every technical file was built without assistance.

## What I learned

The main lesson was that sales support is not only customer communication. The information also has to be complete, correct, and visible to other people.

Every open opportunity should have:

- A current stage
- A responsible person
- A clear next action
- A due date
- Relevant communication notes

I also learned the difference between companies, contacts, and deals; when a quotation is prepared; when approval is needed; and how a won opportunity moves toward Order Management.

## Limitations

- All data is synthetic.
- The dataset contains only 20 opportunities.
- The dashboard is not connected live to HubSpot.
- Only five detailed quotation examples were created.
- The process ends at a simple order handover.
- No real customer conversations or sales results are claimed.
